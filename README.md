# Learning HTML in an AI Era

Practice files for the **Learning HTML in an AI Era** video lessons.

See our [YouTube Channel](https://www.youtube.com/@aitechnologysimplified) for the full tutorial.

AI tools can generate a complete web page in seconds. These lessons give you what you need to read, check and fix the HTML they produce.

## How to use these files

Every lesson folder has the same two folders:

| Folder | What it is |
|--------|------------|
| `starter/` | Use this during the "Your turn" pause in the video. Open `index.html` in your browser and in your editor. |
| `complete/` | The finished version. Compare it with yours afterwards. |

Writing code yourself is optional. If your aim is to understand code rather than write it, just open each page in your browser and read the code alongside it.

## Tips

- Lesson 3: open `starter/index.html` and click between **Home** and **Blog**. The header and footer stay the same; only the main content changes.
- Lesson 6: the forms use `method="get"`, so when you press Send you can see the data in the address bar.
- Lesson 7: run `starter/index.html` through the validator at https://validator.w3.org/nu/ and see which problems it finds, and which it doesn't.
- Your comments and fixes don't need to match mine word for word. If the meaning is the same, you've got it.
