## HTML
- Write valid HTML5: doctype, lang on <html>, UTF-8 charset and the viewport meta tag.
- Use semantic elements (header, nav, main, article, section, footer) before div or span.
- No inline styles or <style> blocks. All CSS goes in an external stylesheet.
- No inline JavaScript or event attributes such as onclick. Scripts go in external files.
- Name classes and ids in lowercase kebab-case that describes purpose, not appearance (main-nav, not blue-bar). Keep each id unique on the page.
- Wrap every attribute value in double quotes. Use single quotes only for quotes inside a value.
- Give every img meaningful alt text (alt="" if it's purely decorative) and every form control a label.
- Use one h1 per page, keep heading levels in order, and make sure the code passes the W3C validator.
